# Brand Voice

## Cel

Brand Voice definiuje sposób, w jaki mówi Pani Migrena.

Nie chodzi tylko o styl pisania.

Chodzi o sposób, w jaki budujemy zaufanie, spokój i poczucie bezpieczeństwa.

Każdy tekst powinien brzmieć tak, jakby został napisany przez tę samą osobę.

---

# Kim jest Pani Migrena?

Pani Migrena jest spokojnym przewodnikiem.

Nie poucza.

Nie ocenia.

Nie straszy.

Nie obiecuje cudów.

Towarzyszy.

---

# Jak mówimy?

Spokojnie.

Prosto.

Z empatią.

Konkretnie.

Bez nadmiaru słów.

Bez medycznego żargonu, jeżeli nie jest potrzebny.

---

# Jak nie mówimy?

Nie dramatyzujemy.

Nie wywołujemy poczucia winy.

Nie moralizujemy.

Nie wywieramy presji.

Nie budujemy lęku.

---

# Nasz język

Mówimy o człowieku.

Nie o "przypadku medycznym".

Mówimy o życiu.

Nie tylko o objawach.

Mówimy o możliwościach.

Nie o ograniczeniach.

---

# Zaufanie

Nigdy nie udajemy lekarza.

Jeżeli czegoś nie wiemy, mówimy o tym otwarcie.

Jeżeli istnieją różne stanowiska, pokazujemy je uczciwie.

Wiarygodność jest ważniejsza niż efekt.

---

# Zapraszamy. Nie wymuszamy.

Nie używamy komunikatów wywierających presję.

Nie projektujemy komunikacji opartej na FOMO.

Nie próbujemy "dopchnąć" użytkownika do działania.

Pokazujemy możliwości.

Pozwalamy użytkownikowi zdecydować.

---

# Projektujemy przestrzeń do refleksji.

Nie każda sekcja musi kończyć się przyciskiem.

Nie każda interakcja wymaga natychmiastowej decyzji.

Dajemy użytkownikowi czas.

---

# Jak piszemy CTA?

CTA jest zaproszeniem.

Nigdy poleceniem.

Nie mówimy:

- Musisz...
- Zacznij natychmiast...
- Nie zwlekaj...

Mówimy:

- Zobacz...
- Poznaj...
- Dowiedz się...
- Jeżeli chcesz...
- Możesz...

---

# Każdy tekst powinien pozostawić użytkownika z poczuciem:

Widzę Cię.

Rozumiem Cię.

To, co przeżywasz, jest prawdziwe.

Nie jest to slogan marki.

To wewnętrzny test jakości komunikacji.

Jeżeli tekst nie wywołuje tego odczucia, wymaga poprawy.
