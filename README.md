# Pani Migrena

> **Nie walczymy z migreną.  
> Walczymy o życie, którego migrena nie powinna odbierać.**

---

# O projekcie

Pani Migrena powstaje jako spokojna, godna zaufania marka dla osób żyjących z migreną.

Naszą misją nie jest walka z migreną.

Naszą misją jest pomaganie ludziom odzyskiwać sprawczość, zrozumienie i wpływ na własne życie poprzez rzetelną wiedzę, praktyczne narzędzia i wsparcie.

Repozytorium **docs** jest jedynym źródłem wiedzy o projekcie. Wszystkie decyzje dotyczące produktu, doświadczenia użytkownika, treści i implementacji powstają tutaj, zanim trafią do repozytorium **www**.
